# Liberty Robotics — FIRST Team 1764

A rebuild of the Team 1764 website, in progress.

**Live preview:** https://garykellygrimm-a11y.github.io/liberty-robotics/

## Status

Design exploration. Three visual directions are being mocked up for the
team to choose from. No production site yet.

## Stack

Currently plain HTML and CSS. Once a direction is chosen, the site will be
rebuilt in React and TypeScript with Vite, deployed to GitHub Pages.

## Working on this

Nothing is pushed directly to `main`. Work happens on a branch and merges
through a pull request.

```bash
git switch -c type/short-slug

# make changes

git add -A
git commit -m "type: what changed"
git push -u origin type/short-slug
```

Branch prefixes: `feat/`, `fix/`, `chore/`, `docs/`, `style/`.
